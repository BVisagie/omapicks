# Security

Please report vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/BVisagie/omapicks/security/advisories/new), not in a public issue.

This covers the code in this repository, its GitHub Actions workflows and the omapicks.com site.

It doesn't cover the plugins OmaPicks lists. A ranking is not a safety review, so report a problem in a plugin to its author or to the [Omarchy Plugins marketplace](https://plugins.omarchy.org/).
