    How we pick

    Recommendations first need reviewed evidence that they complete this category's task. Install-command copies count most, then hearts and GitHub stars. Listing views barely count. Recently updated repositories rank higher than abandoned ones, and a verified snapshot is only a small bonus. The highest-scoring task-qualified plugin is champion, followed by the strongest remaining alternative. Picks stay frozen until the next weekly publication.
